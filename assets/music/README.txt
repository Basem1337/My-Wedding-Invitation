Background music for the invitation.

Current file:
  royal-waltz.mp3 — Mendelssohn Wedding March (public domain)

To use your own track:
  1. Put an MP3/OGG in this folder
  2. Set music.src in js/config.js

Music starts when a guest opens the envelope (browsers block autoplay until a click).
Use the ♪ button to mute / unmute.
